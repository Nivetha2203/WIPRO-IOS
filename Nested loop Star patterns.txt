Nested loop:

Star pattern:

for _ in 1...3 {
    for _ in 1...3 {
        print("*", terminator: " ")
    }
    print()
}


Right triangle star pattern

for i in 1...3{
  for _ in 1...i{
    print("*", terminator: " ")
  }
  print()
}


Increasing number pattern

for i in 1...5 {
    for j in 1...i {
        print(j, terminator: " ")
    }
    print()
}


Repeated row numbers

for i in 1...5{
   for j in 1...i{
       print(i, terminator: " ")
   }
   print()
}
